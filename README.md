# sawt-agent

[English](README.en.md)

**تعطيه نص عربي — يطلع لك رسالة صوتية بنطق صحيح. أو مكالمة هاتف يرد عليها وكيل.**

منصة صوت عربية مبنية على Gemini: pipeline من خمس مراحل يجهّز النص قبل النطق، ووكيل مكالمات حيّ عبر WebSocket، وثلاث قنوات توصيل — تيليجرام، واتساب Cloud API، وهاتف عبر Twilio.

**التكلفة مقيسة: 0.06 ريال لرسالة صوتية طولها 24 ثانية.** بدون رقم هاتف وبدون رسوم اتصال.
4,236 سطر JavaScript، وثلاث تبعيات بس: `express` و `ws` و `dotenv`.

---

## المشكلة

العربي يُكتب بدون تشكيل. الحرف الواحد يحتمل أكثر من نطق، فيقرأ محرّك الصوت
الكلمة غلط، والمستمع ما يفهمها.

الأرقام أسوأ. `8472` رقم طلب، لكن المحرّك ينطقه «ثمانية آلاف وأربعمئة واثنان وسبعون»،
والعميل ما يقدر يكتبه بعد ما يسمعه.

المطلوب: نعرف بالضبط وش بيُنطق **قبل** ما ندفع مقابل توليده.

## كيف يشتغل

النص يعدّي خمس مراحل، وكل مرحلة ترجّع ناتجها عشان يظهر في الواجهة:

| المرحلة | الوظيفة |
|---|---|
| 1. تنظيف | يشيل الإيموجي والتطويل والمسافات الزايدة |
| 2. توسعة الرموز | `ر.س` تصير `ريال` · `15%` تصير `خمسة عشر بالمئة` |
| 3. الأرقام | يفرّق بين الرقم المرجعي والرقم الكمّي |
| 4. التشكيل | يضيف الحركات بنموذج نصي، ومعه حارس يفحص الناتج |
| 5. توجيه الأداء | يطلب من المحرّك صراحة يفرّق بين الضاد والظاء، والصاد والسين |

**الرقم المرجعي مقابل الكمّي:** أي رقم يجي بعد كلمة «طلب» أو «فاتورة» أو «بوليصة»،
أو أي رقم من خمس خانات فأكثر بدون فاصلة آلاف — يُنطق رقم رقم. غيره يُفقَّط كامل.

### العقل مستقل عن القناة

ملف `lib/live.js` ما يعرف من وين جا الصوت. ثلاث قنوات تنادي نفس الجلسة، و `lib/telephony.js` وحده يحوّل الترميز:

| القناة | ترميز الصوت | الحال |
|---|---|---|
| متصفح | PCM 16 كيلوهرتز | يعمل |
| هاتف عبر Twilio | μ-law 8 كيلوهرتز، إطارات 160 بايت | يعمل، وتقدر تفحصه بدون حساب Twilio |
| واتساب Business Calling | Opus | جاهز في الكود، لسه ما ربطته |

أول صوت من الوكيل يجي بعد 1.3 ثانية، مقيسة بـ `scripts/test-live.js`. الوكيل نفسه ينادي أدواته:
يقرأ حالة الطلب، يسجّل طلب العميل، ويحوّل المكالمة لموظف بشري.

## أهم قرار في التصميم

التشكيل أكبر شي يضبط النطق، وما فيه مشكّل عربي دقيق غير نموذج لغوي.
لكن النموذج أحياناً يخرب: يعيد صياغة الجملة بدل ما يشكّلها بس.

رسالة عميل يتغيّر نصها أسوأ من رسالة بدون تشكيل.

**القرار: حارس يفحص، وله حق يرفض ناتج النموذج.** بعد التشكيل نشيل الحركات من الناتج،
ونقارنه بالنص الأصلي حرف بحرف. إذا نزل التطابق تحت 90٪، نرمي الناتج
ونرجع للنص الأصلي، والسبب يظهر في الواجهة.

الثمن: نداء نصي زيادة، وأحياناً نطق أضعف.
المقابل: اللي يُنطق هو اللي مكتوب، دايماً، بلا استثناء.

## التشغيل

```bash
npm install                  # ثلاث تبعيات
cp .env.example .env         # ضع مفتاح Gemini وتوكن بوت تيليجرام
node server.js               # الواجهة على http://localhost:4630
```

يحتاج Node.js 22.5 أو أحدث (عشان `node:sqlite` المدمج)، و `ffmpeg` في `PATH`.

في `scripts/` ثمانية سكربتات فحص: سبعة اختبارات وفاحص حصة.
