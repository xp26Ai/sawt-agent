# sawt-agent

[English](README.en.md)

**نص عربي يدخل — رسالة صوتية صحيحة النطق تخرج. أو مكالمة هاتفية يرد عليها وكيل.**

منصة صوت عربية فوق Gemini: خط تجهيز نطق من خمس مراحل، ووكيل مكالمات حيّ عبر WebSocket، وثلاث قنوات توصيل — تيليجرام، واتساب Cloud API، وهاتف عبر Twilio.

**التكلفة المقيسة: 0.06 ريال للرسالة الصوتية مدتها 24 ثانية.** بلا رقم هاتف وبلا رسوم اتصال.
4,236 سطر JavaScript، وثلاث تبعيات فقط: `express` و `ws` و `dotenv`.

---

## المشكلة

العربية تُكتب بلا تشكيل. الحرف الواحد يحتمل أكثر من نطق، فيقرأ محرّك الصوت
الكلمة خطأً ولا يفهمها المستمع.

والأرقام أسوأ. `8472` رقم طلب، لكن المحرّك ينطقه «ثمانية آلاف وأربعمئة واثنان وسبعون»،
فلا يستطيع العميل كتابته بعد سماعه.

المطلوب: أن نعرف بالضبط ما الذي سيُنطق **قبل** أن ندفع مقابل توليده.

## كيف يشتغل

النص يمر بخمس مراحل، وكل مرحلة تُرجع ناتجها ليظهر في الواجهة:

| المرحلة | الوظيفة |
|---|---|
| 1. تنظيف | يزيل الإيموجي والتطويل والمسافات الزائدة |
| 2. توسعة الرموز | `ر.س` تصير `ريال` · `15%` تصير `خمسة عشر بالمئة` |
| 3. الأرقام | يفرّق بين الرقم المرجعي والرقم الكمّي |
| 4. التشكيل | يضيف الحركات عبر نموذج نصي، خلف حارس تحقّق |
| 5. توجيه الأداء | يطلب صراحةً التمييز بين الضاد والظاء، والصاد والسين |

**الرقم المرجعي مقابل الكمّي:** الرقم الواقع بعد كلمة «طلب» أو «فاتورة» أو «بوليصة»،
أو أي رقم من خمس خانات فأكثر بلا فاصلة آلاف، يُنطق رقماً رقماً. وغيره يُفقَّط كاملاً.

### العقل مستقل عن القناة

ملف `lib/live.js` لا يعرف من أين جاء الصوت. ثلاث قنوات تستدعي نفس الجلسة، وطبقة `lib/telephony.js` وحدها تحوّل الترميز:

| القناة | ترميز الصوت | الحال |
|---|---|---|
| متصفح | PCM 16 كيلوهرتز | يعمل |
| هاتف عبر Twilio | μ-law 8 كيلوهرتز، إطارات 160 بايت | يعمل، ويُختبر بلا حساب Twilio |
| واتساب Business Calling | Opus | معدّ في الكود، غير مربوط |

أول صوت من الوكيل بعد 1.3 ثانية، مقيساً بـ `scripts/test-live.js`. والوكيل يستدعي أدواته بنفسه:
قراءة حالة الطلب، تسجيل حاجة العميل، التحويل إلى موظف بشري.

## أهم قرار في التصميم

التشكيل هو أقوى عامل في صحة النطق، ولا يوجد مشكّل عربي دقيق إلا نموذج لغوي.
والنموذج يخون أحياناً: يعيد صياغة الجملة بدل أن يشكّلها فقط.

رسالة عميل تغيّر نصّها أسوأ من رسالة بلا تشكيل.

**القرار: حارس تحقّق يرفض ناتج النموذج.** بعد التشكيل ننزع الحركات من الناتج،
ونقارنه بالنص الأصلي حرفاً بحرف. إذا نزل التطابق تحت 90٪، نرمي الناتج
ونرجع إلى النص الأصلي، ويظهر السبب في الواجهة.

التكلفة: نداء نصي إضافي، وأحياناً نطق أضعف.
العائد: النص المنطوق هو النص المكتوب دائماً، بلا استثناء.

## التشغيل

```bash
npm install                  # ثلاث تبعيات
cp .env.example .env         # ضع مفتاح Gemini وتوكن بوت تيليجرام
node server.js               # الواجهة على http://localhost:4630
```

يحتاج Node.js 22.5 فأحدث (لأجل `node:sqlite` المدمج)، و `ffmpeg` في `PATH`.
